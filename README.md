# 📊 가족 증권계좌 실시간 ETF 변동 추적 및 장 마감 알림 웹앱

본인(김영집), 둘째(김하율), 첫째(김은비) 가족 증권계좌의 국내 상장 ETF 6종 실시간 시세와 평가금액, 손익률을 한눈에 추적하고, 장 마감 시 텔레그램으로 일일 결산 알림을 발송하는 모던 반응형 웹앱입니다.

---

## 🌟 주요 기능

1. **실시간 시세 자동 갱신 (무료 오픈 API)**
   - 별도 증권사 API Key 발급 없이 네이버 증권 오픈 API를 통해 실시간 호가 및 전일비 등락률 수집
   - 15초 주기 자동 새로고침 및 수동 새로고침 버튼 제공
   - 국내 정규장 운영 상태(개장 중 / 장 마감 / 주말 휴장) 실시간 판별

2. **직관적인 대시보드 레이아웃**
   - **가족 통합 요약**: 총 순자산, 총 매입금액, 총 주식평가액, 누적 손익 및 수익률, 당일 손익 변동액 표시
   - **3단 병렬 뷰 (Columns View)**: 데스크톱 화면에서 세 계좌를 나란히 비교
   - **탭 뷰 (Tabs View)**: 모바일/태블릿에 최적화된 계좌별 상세 탭 조회
   - **비주얼 차트**: ETF 종목별 자산 비중 도넛 차트 및 종목별 수익률 비교 바 차트

3. **웹 화면 내 포트폴리오 직접 관리**
   - [✏️ 계좌 수정] 모달을 통해 주식 수량, 매입단가, 예수금을 직접 수정/저장 가능
   - [➕ 신규 종목 추가] 기능으로 새로운 ETF 종목도 간편하게 등록 가능
   - 브라우저 로컬 저장소(`localStorage`)에 자동 보존되어 새로고침해도 데이터 유지
   - [💾 데이터 관리]: JSON 백업 파일 다운로드 및 복원, 원본 초기화 기능 제공

4. **장 마감 텔레그램 일일 결산 알림**
   - 웹 화면 우측 상단 [⚙️] 버튼에서 텔레그램 Bot Token과 Chat ID 등록
   - [🔔 지금 테스트 알림 발송] 버튼으로 모바일 텔레그램 수신 즉시 확인
   - Vercel 호스팅 시 `vercel.json`에 정의된 Cron Job으로 평일 15:35 자동 일일 마감 리포트 전송

---

## 🚀 로컬 실행 방법

1. **의존성 패키지 설치**
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   브라우저에서 `http://localhost:3000` 접속

3. **프로덕션 빌드 및 실행**
   ```bash
   npm run build
   npm run start
   ```

---

## 🌐 Vercel 무료 배포 방법

1. GitHub 저장소에 코드를 push합니다.
2. [Vercel](https://vercel.com)에 로그인 후 해당 저장소를 Import합니다.
3. (선택 사항) Vercel 프로젝트 설정의 **Environment Variables**에 다음 환경변수를 등록합니다:
   - `TELEGRAM_BOT_TOKEN`: 텔레그램 봇 토큰
   - `TELEGRAM_CHAT_ID`: 텔레그램 Chat ID
4. **Deploy** 버튼을 누르면 스마트폰, 태블릿, PC 어디서나 접속 가능한 고유 URL이 생성됩니다.
5. Vercel Cron(`vercel.json`)이 평일 15:35에 자동으로 장 마감 리포트를 텔레그램으로 전송합니다.

## 📱 텔레그램 봇 생성 가이드 (1분 소요)

1. 텔레그램 앱에서 **@BotFather**를 검색하고 대화를 시작합니다.
2. `/newbot`을 입력하고 봇 이름과 사용자명을 설정합니다.
3. 발급된 **HTTP API Token** (예: `7123456789:AAF...`)을 복사합니다.
4. 텔레그램 앱에서 **@userinfobot**을 검색하고 메시지를 보내 나의 **Id**(숫자)를 확인합니다.
5. 생성한 내 봇에게 먼저 아무 메시지(예: `/start`)나 1회 전송합니다.
6. 웹앱 우측 상단 [⚙️] 설정 창에 토큰과 Chat ID를 입력하고 **[지금 텔레그램으로 테스트 리포트 발송]**을 누릅니다.
